# GuiWheyLabs MakerWorld originals

Public download packages of original GuiWheyLabs 3D-print designs, prepared so they can be uploaded to MakerWorld.

This repository only hosts files. It is not a MakerWorld upload, does not accept MakerWorld terms, and does not publish models on MakerWorld.

Each release asset is one zip per design. Every zip contains:

- print-ready 3MF (Bambu X2D / Generic PETG profile) plus the STL
- listing images
- `listing.txt` with title, description, and tags

Download the zip assets from [Releases](https://github.com/GuiWhey/guiwheylabs-makerworld-originals/releases). Use the `batch-01` release for the first four packages.

Designs are original GuiWheyLabs geometry. Images in the first batch are studio renders, CAD drawings, or composites unless a listing says otherwise. Several items are untested; read `listing.txt` before publishing.
