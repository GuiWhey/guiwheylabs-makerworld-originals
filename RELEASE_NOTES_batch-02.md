Batch 02 - sixteen original packages, sliced for the Bambu Lab P1S.

Each zip contains a Bambu Studio project 3MF per part (Bambu Lab P1S, 0.4 mm nozzle, 0.20 mm Standard, Generic PETG, Textured PEI, one plate on the 256 mm bed, slice embedded), the STL(s), true-geometry studio renders (4:3 cover first) and listing.txt with title, description, tags, real slicer estimates and honest notes.

Nothing in this release was uploaded to MakerWorld. Every part is untested unless its listing says otherwise; slicer numbers are estimates. Several parts use most of the 256 mm bed (see each listing for the bed use including brim).
