Batch 06 - five new original packages, sliced for the Bambu Lab P1S and P2S.

Each zip contains:
- a Bambu Studio project 3MF for the Bambu Lab P1S (0.4 mm nozzle, stock "0.20mm Standard @BBL X1C" process, stock "Generic PETG" filament, Textured PEI), model on Plate 1, every plate sliced;
- a Bambu Studio project 3MF for the Bambu Lab P2S (0.4 mm nozzle, stock "0.20mm Standard @BBL P2S" process, stock "Generic PETG @BBL P2S" filament), every plate sliced;
- the STL(s), four distinct true-geometry studio renders (4:3 cover first) and listing.txt (title of 50 characters or fewer, description, print settings, tags, real slicer estimates, honest notes).

Both 3MFs reference the stock Bambu system presets (inherits_group) and list only the changed keys in different_settings_to_system, so Bambu Studio should keep the settings on File > Open Project.

Nothing in this release was uploaded to MakerWorld. Every part is untested; slicer numbers are estimates. The 3MF thumbnails, printer id and preset-inheritance fields were added by a post-process, not generated by Studio.
